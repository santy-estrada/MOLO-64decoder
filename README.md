# Easy Molonari Decoder

In the file `decode.py`, look for the hardcoded line to decode. You just have to change it for your own.

## To Use
You must have pixi installed in your PC. Run `pixi install` in the folder to install all the pyhton dependencies.

## To Run
Just run `pixi run decode` on your terminal. The output will be the decoded data.
